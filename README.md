# Muchi

Discover 700+ record shops across Japan. A single self-contained page (`index.html`): shop data, fonts and the map are all inlined, so it can be hosted anywhere as a static file.

Lives at https://muchi.space. Moved out of ericroberts.net/dig (where it was called "dig") on 2026-11-20.

## Hosting
GitHub Pages from `main`, custom domain in `CNAME` (muchi.space, registered at Namecheap).
